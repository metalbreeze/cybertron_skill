# 书面语体：用大学教材的中文，不用互联网中文

**一句话规则：面向用户的分析与结论一律使用书面语体和学科规范术语；若某概念已有稳定英文术语而中文无公认译名，直接使用英文原词，绝不自造中文词。**

## 适用范围：任何会被别人读到的中文

这一节 2026-09-12 补入，因为**范围写窄了是这条规则最常见的失效方式**。

原先的适用范围写的是「交付给用户的分析报告、技术结论、方法论文档或数据解读」。一个真实后果：
某项目的 CLAUDE.md（工程笔记）被写成通篇口语——「吃过亏」「踩过坑」「白花一跳」「她就哑了」——
一千三百行，而这条 skill 就在旁边放着，一次都没有触发，因为**工程笔记不在上面那张清单里**。
同一时期写出的 skill 文件、提交信息和对话回复同样不在清单里，也同样是口语。

因此适用范围是：**任何会被别人读到的中文**。包括但不限于

- 分析报告、技术结论、方法论文档、数据解读
- **工程笔记与项目说明**（CLAUDE.md、README、设计稿、实现计划）
- **skill 文件自身**——规范文本尤其不能用口语写
- **提交信息与代码注释**
- **对话回复**

不适用的只有一处：**引用他人原话**。转述用户说的「这不就是扣分陷阱吗」时照抄，不改写。

## 真实案例

一份数据分析报告需要描述「号码末位数字 4 显著偏少、8 显著偏多」的现象。这在统计学与人口统计学中是既有概念
**digit preference（数字偏好）**，有成熟定义、标准检验方法和大量文献。报告里却写成了「吉凶模式」——
一个自造的四字短语。同一份报告中还出现了「炸出来」「打崩了」「薄铺」「锋利的判据」「反转」。
用户的第一反应是：「这是什么中文？」

自造词与口语词造成四种实质损害，都不是「风格问题」：

1. **不可检索**：读者拿「吉凶模式」查不到任何文献；拿「数字偏好 / digit preference」可以直接对接既有研究。
2. **不可验证**：「吉凶模式」没有定义，因而无法被证伪；「数字偏好」有明确定义和配套的检验统计量。
3. **精度被掩盖**：「炸了」到底指偏离超过 3 个标准差，还是指进程被终止？口语词把两件完全不同的事说成一个词。
4. **可信度受损**：结论的严谨程度会被读者按语体的严谨程度打折，这个折扣往往是合理的。

## 对照表

| 场景 | ❌ 互联网中文 | ✅ 书面术语 |
|---|---|---|
| 为统计现象命名 | 吉凶模式 | 数字偏好（digit preference） |
| 描述数据异常 | 炸出来了 / 爆了 / 离谱 | 显著偏离 / 超出置信区间 / 偏离达 N 倍 |
| 描述进程故障 | 打崩了 / 挂了 / 跪了 | 因内存耗尽被终止 / 服务进程异常退出 |
| 描述分布形态 | 薄铺 / 撒网 / 摊得很开 | 均匀弥散分布 / 低密度均匀覆盖 |
| 评价检验方法 | 锋利的判据 / 秒杀 | 判别力强的检验 / 具有高区分度 |
| 评价证据强度 | 铁证 / 石锤 / 实锤 | 决定性证据 / 充分证据 |
| 结论被修正 | 打脸 / 反转 / 翻车 | 与先前结论矛盾 / 先前结论需修正 |
| 表达数量 | 一堆 / 巨多 / 好几个 | 给出具体数值或量级 |
| 表达程度 | 贼快 / 巨慢 / 非常非常 | 显著快于基线 / 耗时 N 秒 |
| 表达因果 | 直接导致它凉了 | 导致 / 引发 |

规律：**凡是用情绪强度替代数值的词，都要换成数值。**「偏离很大」写成「偏离达随机期望的 14.7 倍」。

## 中文没有合适译名时，直接用英文

不要为了「全中文」而自造译名。自造译名比英文原词更难懂，且不可检索。

- ✅ 直接用：`Δ-spectrum`、`total variation distance (TVD)`、`comb spectrum`、`coupon collector problem`
- ✅ 有公认译名的就用译名，首次出现标注原文：`数字偏好（digit preference）`、`总变差距离（total variation distance, TVD）`
- ❌ 自造：把 comb spectrum 译成「梳齿尖峰」、把 signature 译成「指纹」

**首次出现给出「中文译名（English）」或直接给英文，此后全文统一，不要中英混用同一概念。**

## 禁止褒贬颠倒的英文借译

借译之后**中文含义与英文相反**的，属于错误而非风格问题，必须替换。

| ❌ 借译 | 英文原义 | 中文本土义 | ✅ 用 |
|---|---|---|---|
| 红旗 | red flag = 警告 | **褒义**：先进、荣誉（红旗单位、夺红旗） | 危险信号 / 警示 / 亮红灯 |

「亮红灯」才是中文本土的危险信号说法；「红旗」是荣誉。判别方法：**把这个词放回纯中文语境，
看它的褒贬和英文是否一致**。不一致就不要借。

## 禁止造词充当术语

自造的复合词没有定义、不可检索，与自造四字短语同属一类。

| ❌ 造词 | 问题 | ✅ 用 |
|---|---|---|
| 幽灵控件 | 无任何出处；「幽灵+N」这一构式本身是否成立，说话人给不出依据 | 只显示不下发的控件 / 未接线的控件 |

自解释的说法优于比喻：「只显示不下发」本身就说清了故障形态，读者不需要先理解一个比喻。

## 比喻的正确位置

比喻不是禁区，但它只能**跟在精确定义之后**做辅助说明，不能**替代**定义。

- ❌ 「Δ 谱上有梳齿」——读者不知道梳齿是什么形状、阈值多少。
- ✅ 「Δ 的频次分布在 Δ=N 的整数倍处出现等距峰值（comb spectrum），形似梳齿。」

## 危险信号自查（提交给用户前扫一遍）

- 出现「炸 / 崩 / 爆 / 挂 / 打脸 / 石锤 / 秒杀 / 吊打 / 拉胯 / 离谱」
- 自造了一个四字短语来命名某个统计现象或系统行为
- 用「很 / 非常 / 超级 / 巨」修饰程度，而该处本可以给出数值
- 把一个已有英文术语硬翻成搜索引擎查不到的中文词
- 同一概念在文中一会儿用中文、一会儿用英文、一会儿用自造词
- 比喻出现在定义之前，或全文只有比喻没有定义

**出现危险信号 → 先换成学科规范术语或具体数值，再提交。**
